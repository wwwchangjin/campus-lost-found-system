# 校园失物招领与暂存认领系统——需求调研计划

**项目名称：** 校园失物招领与暂存认领系统  
**项目阶段：** 第9周——项目启动与需求调研  

## 1. 调研背景

校园内失物招领信息可能分散于微信群、QQ群、校圈、校园信息平台及线下失物招领点，存在信息检索不便、认领流程不统一、暂存状态不透明等潜在问题。

本项目拟建设校园失物招领与暂存认领系统，为师生和管理人员提供失物登记、信息查询、物品暂存、身份核验及认领管理等服务。

上述问题目前属于初步假设，需要通过实际调研验证。

## 2. 调研目标

1. 了解高校师生遗失、拾得及寻找物品的真实经历与处理流程。
2. 分析现有失物招领方式的使用情况及主要痛点。
3. 了解校园失物暂存点的登记、保管、认领和异常处理流程。
4. 调查用户对失物信息发布、检索、通知和认领功能的需求。
5. 分析身份核验、隐私保护、重复认领等业务风险。
6. 为后续用户故事、用例建模和软件需求规约（SRS）提供依据。

## 3. 调研对象

| 调研对象 | 调研重点 | 调研方式 |
|---|---|---|
| 曾遗失物品的学生 | 寻物渠道、找回经历、主要困难 | 访谈、问卷 |
| 曾拾得物品的学生 | 招领方式、移交流程、信息发布意愿 | 访谈、问卷 |
| 其他在校师生 | 需求普遍性、功能偏好、隐私顾虑 | 问卷 |
| 校园失物暂存点工作人员 | 接收、登记、保管、核验、领取流程 | 访谈、流程观察 |

## 4. 调研方法

### 4.1 用户访谈

本次调研采用半结构化访谈方式，针对不同业务参与者分别设计访谈问题，重点了解校园失物招领的实际业务流程、现有处理方式、用户痛点及潜在需求。

#### （1）曾遗失物品的学生

**调研目标：** 了解学生遗失物品后的寻找过程、信息获取渠道、找回困难以及认领过程中的实际体验。

**参考问题：**

1. 请回忆一次您在校园内遗失物品的经历，当时是什么情况？
2. 发现物品遗失后，您采取了哪些措施寻找？整个寻找过程是怎样的？
3. 您当时通过哪些渠道获取失物信息？为什么选择这些渠道？
4. 在寻找物品的过程中，您遇到过哪些困难或不方便的地方？
5. 如果有人联系您并表示找到了您的物品，您通常会如何确认对方找到的确实是您的物品？
6. 如果需要到校园失物暂存点认领物品，您希望提前了解哪些信息？您是否有过实际的认领经历？
7. 在寻找或认领物品的过程中，您是否遇到过个人信息泄露、虚假招领或其他让您担忧的情况？
8. 回顾整个经历，您认为目前校园失物寻找方式最需要改善的地方是什么？

#### （2）曾拾得物品的学生

**调研目标：** 了解学生拾得他人物品后的处理方式、寻找失主的过程、信息发布习惯以及物品移交过程中存在的问题。

**参考问题：**

1. 请回忆一次您在校园内拾得他人物品的经历，当时是什么情况？
2. 拾得物品后，您是如何处理的？为什么选择这种处理方式？
3. 如果您尝试过寻找失主，具体通过哪些渠道或方式寻找？过程是否顺利？
4. 在发布招领信息或联系失主时，您遇到过哪些困难？
5. 如果有人声称物品属于自己，您通常如何判断对方是否是真正的失主？
6. 您是否曾将拾得物品交给校园工作人员或失物暂存点？如果有，移交流程是怎样的？
7. 物品交出后，您是否会关注它的后续处理结果？您通常如何得知物品是否被领回？
8. 您认为目前校园内拾得物品后的处理流程有哪些值得改善的地方？

#### （3）校园失物暂存点工作人员

**调研目标：** 了解校园失物暂存管理的完整业务流程、现有管理制度、工作难点和异常情况处理方式，为系统管理功能及业务规则设计提供依据。

**参考问题：**

1. 请您介绍一下，目前暂存点从接收到拾得物品，到物品最终被领走或进行其他处理，通常经历哪些步骤？
2. 收到拾得物品后，工作人员通常需要登记哪些信息？目前采用什么方式记录和管理？
3. 物品在暂存期间如何进行分类、编号、保管和查找？日常管理中有哪些困难？
4. 当失主前来认领时，通常需要提供哪些证明信息？工作人员如何核实认领人的身份及物品所有权？
5. 如果出现多人认领同一物品、认领信息不符或者物品存在争议的情况，目前如何处理？
6. 对于长期无人认领的物品，是否有明确的保管期限及后续处理规定？实际工作中如何执行？
7. 目前暂存点通过哪些方式发布招领信息或通知失主？这些方式在实际使用中存在哪些不足？
8. 在日常管理中，哪些环节最耗费时间或最容易出错？您认为哪些工作流程最需要改进？

#### （4）访谈实施计划

| 项目 | 计划 |
|---|---|
| 访谈形式 | 线下访谈为主，必要时线上访谈 |
| 曾遗失物品的学生 | 计划访谈3–5人 |
| 曾拾得物品的学生 | 计划访谈3–5人 |
| 校园失物暂存点工作人员 | 争取访谈1–2人 |
| 单次访谈时长 | 预计15–20分钟 |
| 记录方式 | 经受访者同意后，采用文字记录或录音 |
| 预期成果 | 匿名访谈纪要、现有业务流程、痛点清单、初步需求清单 |

访谈开始前向受访者说明调研目的及信息使用范围。问题作为访谈提纲，不要求机械地逐题询问，可以根据实际回答追问具体经历和业务细节。

调研结束后，对不同角色的访谈结果分别整理，再分析各角色之间的业务联系与需求差异。

### 4.2 问卷调查

**调查对象：** 在校师生。

**建议规模：** 不少于30份有效问卷。

**问卷设计：** 10–15题，填写时间控制在5分钟以内。

调查内容包括：

- 失物遗失或拾得经历及频率
- 当前使用的寻物、招领渠道
- 现有渠道的使用满意度
- 信息搜索与分类需求
- 物品暂存和认领需求
- 消息通知需求
- 身份核验与隐私保护关注度

**预期产出：** 问卷原始统计数据、统计图表、主要问题分析。

### 4.3 现有系统与评论分析

收集公开可获取的校园失物招领信息、用户评论或相关平台反馈。

重点分析：

1. 信息发布是否规范。
2. 信息是否容易检索。
3. 招领与认领是否形成完整流程。
4. 用户对管理效率和隐私保护的反馈。

**预期产出：** 典型问题记录与痛点分类表。

### 4.4 竞品分析

选择2–3个现有失物招领平台或具有类似功能的系统进行比较。

主要比较：

- 寻物与招领信息发布
- 分类检索与信息筛选
- 物品状态追踪
- 身份核验及认领审核
- 消息通知
- 管理权限与异常处理

**预期产出：** 竞品功能对比表、可借鉴方案和差异化机会。

## 8. 调研质量与风险控制

- 访谈和问卷须基于真实参与者，不得编造调查结果。
- 对收集的个人信息进行匿名化处理，不在公开仓库上传姓名、电话、学号等敏感数据。
- 区分已确认的需求与未经验证的功能设想。
- 对存在分歧的需求记录来源和待确认事项。
- 对无法联系到暂存点工作人员的情况如实说明，并制定补充调研方案。
- 所有调研文档通过 GitHub Issue、PR 进行版本管理与团队评审。

## 9. 后续工作
